## Sending, terminal, Files and panes

| Keys | What it does |
| --- | --- |
| <kbd>Enter</kbd> | Send. While the agent works: send now, into the running turn ([Agent steering](/steering/)) |
| <kbd>Alt+Enter</kbd> | While the agent works: send after this turn |
| <kbd>Ctrl+`</kbd> / <kbd>Ctrl+J</kbd> | Open the chat's terminal; pressed in the terminal, hide it |
| <kbd>Ctrl+Shift+E</kbd> | Switch the sidebar between Chats and Files |
| <kbd>Ctrl+Shift+F</kbd> | Filter files in Files |
| <kbd>Ctrl+\\</kbd> | Split the current tab into a new pane |
