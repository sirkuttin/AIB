## 0.1.0-beta.9

[Downloads on GitHub](https://github.com/sirkuttin/AIB/releases/tag/v0.1.0-beta.9)

> **Beta.** Builds are not code-signed. Expect rough edges. Install and download notes are the same as in [0.1.0 beta 1](https://github.com/sirkuttin/AIB/releases/tag/v0.1.0-beta.1).

Your agents no longer stall because you stepped away. In beta 9, your phone becomes a remote for every chat in AIB: approve, answer and start work from the couch, the train or the shop, for Claude Code, Codex, OMP and the rest. It runs over your own Tailscale network, so nothing goes through a cloud service of ours. You can also correct an agent mid-turn: press Enter while it works and it hears you right away, instead of finishing the wrong job first. On top of that: a tidy Artifacts list, a `private/` folder every chat can see that git never commits, and an **Update** button so you never miss a new AIB.

### What's new

#### Remote control: answer your agents from your mobile phone

<Shot name="phone-cards.png" alt="The phone page: chat cards with needs-you chats first" phone />
An agent that stops to ask "may I run this?" used to wait until you were back at your desk. Now the question reaches your pocket, and you answer it there.
- **Push notifications tell you the moment a chat needs you or finishes**, even with the AIB window closed. They use standard Web Push: no account, no app store.
- **Do real work from the phone, not just watch.** Every chat is a card, needs-you first. Read along, answer questions, approve, send, stop, and check artifacts with their versions. **New chat** starts work in any project with any agent, model and mode.
- **Cross-agent:** Claude Code, Codex, OMP and the other agents all work the same from the phone.
- **Local:** traffic stays between your phone and your PC, on your own Tailscale network, on a port of its own. The PC page's own security checks are unchanged.
- **You stay in charge of each phone.** Pair by QR code or six words, then approve it on the PC. Each phone gets its own switches (Answer, Send, Approve once, Start new chats, Push, Silent reminders), a **Phone activity** log and **Remove**.
- **Set up in four buttons** under **Settings → Remote control**. AIB runs the Tailscale commands for you, lists everything it changed on this PC, and undoes it with **Stop sharing** and **Turn off Funnel**.
- **Add it to your home screen** with **Install AIB**, pick a theme per phone, and mark, rename, archive or delete chats from the card menu. Renames and unread dots carry over to the PC.
- **Closing the window keeps AIB in the tray while phone access is on**, so your phone keeps working. **Settings → AIB server → Keep the PC awake while AIB runs** stops the PC sleeping on you.

#### Agent steering: talk to the agent while it works, instead of waiting for the turn to end

<Shot name="steering-send-menu.png" alt="The Send menu open with Send now, Send after this turn and Interrupt and send" />
You see the agent heading the wrong way. Before, your correction sat in a queue while it finished the wrong thing. Now Claude Code, Codex and OMP hear you mid-turn and answer right away.
- **Press Enter while the agent works** and your message goes into the running turn. A command or helper it had running keeps going in the background, so no work is thrown away. These messages are tagged **Sent while working**.
- **Choose how hard to cut in** from **Send ▾**: **Send now** (Enter), **Send after this turn** (Alt+Enter), or **Interrupt and send**. Each says in one grey line what that agent will do with it.
- **Stop one runaway command without stopping the agent.** A command moved to the background shows **Still running in the background** with **Stop**, which ends exactly that command's processes.
- **Claude Code now writes a short reply of its own after you Stop a backgrounded command.** Expect that extra message; it is Claude Code confirming what it stopped.
- **Works from everywhere you type:** the inbox and the phone steer the same way. A message typed while an approval card is open goes in as soon as you answer the card. Agents that can't take messages mid-turn send at the end of the turn, and slash commands and AIB's own messages, such as merge requests, always wait.

#### Artifacts: Archive and Delete clear out the list

<Shot name="artifacts-menu-archive-delete.png" alt="The ⋯ menu on an artifact with Archive and Delete" />
Long chats pile up drafts, old mockups and dead ends until the one artifact you want is hard to find. Now you can clear them out.
- **Archive** hides an artifact and keeps it whole. **Archived N** at the foot of the list brings it back.
- **Delete removes the artifact's file too**, into **Recently deleted** for 30 days. **Undo** is there for 10 seconds and **Restore** after that; **Delete now** removes it for good.
- **Delete won't take files that aren't the artifact's alone.** Files outside the chat's folder, in `aib-docs` or `.git`, or still used by another artifact are kept.
- **Agents can tidy up too:** ask any agent to archive its chat's artifacts. Only you can delete. Old links say **· archived** or **· deleted** instead of breaking.
- Find both in the **⋯** menu on each artifact in the list (or right-click), and in the viewer's **⋯** menu.

#### Manage non-git assets: `private/` folder keeps notes out of git and in front of every chat

<Shot name="private-local-only.png" alt="Files showing the private folder with its blue local only label" />
Some files should never be committed (scratch notes, plans, research), yet every agent should be able to read them. Now there's one folder for them.
- **AIB now adds `private/` to each git project's `.git/info/exclude`** the first time a chat opens there, and creates an empty `private/` folder once a chat works in its own copy. That's a visible change: you'll see the folder, and git never commits it. Projects that already commit a `private/` folder are left alone.
- **Every chat sees it**, including chats working in their own copy, under **Files** with a blue **local only** label.
- **Every agent knows it's there**, whichever provider: they're told where the local-only files are and may write there.
- **Nothing local-only leaks into main.** Files an agent writes into its own copy by mistake move to the shared folder before the copy is removed, and merges never carry them into main.
- **Make any file local-only** by right-clicking it in **Files** and choosing **Git exclude**, with **Undo** for 10 seconds.
- **AIB keeps a zip backup** of each project's local-only files, refreshed daily when they change.

#### AIB Updates: Update button tells you when a new AIB is ready and installs it in one click

<Shot name="updates-button.png" alt="The teal Update button at the top right of the AIB window" />
- A teal **Update** button shows at the top right as soon as a new AIB is ready. One click installs it. If chats are working and can't be carried over, it waits for them to finish.
- One desktop notification per new version, even while AIB sits in the tray.
- After an update, a **What's new** tab shows what changed, newest release first.

#### External File Viewer: when a chat references a file outside the project, you can still open it to view
- When an agent mentions a full path to a file outside your project, it's now a link. It opens read-only in an **Outside this project** tab, and pictures show as pictures.

### Fixes
- **Files** names a chat's copy after the chat, not its branch, and ignored rows say "Ignored by git".
- A project with no open chat shows the new-chat view instead of another project's chat, and **Files** browses the project folder without a chat open.
- **↓ Latest** no longer appears while you're following the chat with a long draft in the message box.
- New docs show in **Files** right away, and doc tabs open after a restart even if their chat is gone.
- Right-column tab labels and long project names in the sidebar now fit.
- Very long chats no longer slow the keeper down.
- The sidebar's ⋯ menu is gone, so there's less to click past.

### Tested
Run with nothing uncommitted on the release branch, one commit before the version bump (Windows 11):
- App-side tests: 1,804 passed, 0 failed, slow real-build tests included.
- Page tests: 1,324 passed, 0 failed.
- Worktree end-to-end tests: 20 passed.
- Server comparison tests: 6 of 6 groups passed. After the version bump, the update, page and comparison tests ran again on the release commit.
- Includes the steer tests against recorded traffic from the real Claude Code, Codex and OMP adapters, layout tests of the Send menu at six widths, and real-build tests of the tray with phone access on.
- Phone remote control tried by hand on a real Android phone: pairing by QR and words, push, chats, new chat, the card menu, themes, artifact versions and the installed app.

Not tested: iPhone, the Tailscale install on macOS and Linux, and macOS and Linux builds beyond building them.

## 0.1.0-beta.8

[Downloads on GitHub](https://github.com/sirkuttin/AIB/releases/tag/v0.1.0-beta.8)

> **Beta.** Builds are not code-signed. Expect rough edges. Install and download notes are the same as in [0.1.0 beta 1](https://github.com/sirkuttin/AIB/releases/tag/v0.1.0-beta.1).

Docs arrive: local documents that every agent can read and write, whichever provider it comes from. Claude Code, Codex, OMP and the rest share the same docs, on your computer, in your project. Quitting AIB no longer stops your chats, and a new build picks them up where they were. Scrolling a chat is rebuilt so it only moves when you move it. Agents merge their own work, subagents show what they're doing, and a Limits chip shows how much of your plan you've used.

### What's new

#### `aib-docs`: local docs every agent can read and edit

<Shot name="docs-comment-thread.png" alt="A doc open in the Artifacts tab with a comment thread and an agent reply" />
- **Cross-agent:** a doc Claude Code starts, Codex can edit and OMP can comment on. Every agent in AIB gets the same doc tools, so you can hand a doc from one provider's agent to another's.
- **Local:** docs are files in your project's `aib-docs/` folder, always the first row in **Files**. No cloud service, no account, and they travel with the project's git history.
- Ask any agent for "a doc" and it writes one. You and your agents type in the same doc at once, and an agent's edit never overwrites yours.
- Pages, rich blocks (callouts, columns, colours, tables, charts, Excalidraw drawings), comments agents can reply to, and a 30-day history you can restore from.

#### Docs open in the Artifacts tab, or as a tab from Files
- A doc from a chat opens in the right column's **Artifacts** tab with the full editor; from **Files** it opens as a tab.
- The right column widens to 920 px while a doc or artifact is open, and never shrinks a column you made wider.
- Markdown artifacts have an **Edit** button.

#### Quit AIB leaves your chats running in the keeper
- Quitting no longer stops anything: agents, helpers and background commands keep going, and the next AIB you start picks them up where they were, even a new build from another folder.
- **Stop all chats and quit** in the tray menu stops everything on purpose.

#### Agents merge their chat into main themselves
- New chats start from main. The agent merges finished helpers into its own copy, and merges its work into main on its own once it's done and tested, or when you ask. No button needed. Each merge posts a **Merged into main** line in the chat.
- If main has moved, the agent brings main into its copy and fixes any conflicts there first. Main only ever gets a clean merge.

#### Subagent cards show model, tokens and what each is doing

<Shot name="chats-subagent-card.png" alt="A working subagent card with model, tokens, run time and current action" />
- A working subagent is a card: its model, type, tokens used, run time, and what it is doing right now ("Running: …", "Editing chat.js").
- A finished one is a single line with its model, how long it ran, and Failed or Stopped when it didn't finish normally.
- The subagent's header shows the model and tokens. **Stop** sits on its title row and confirms in place.
- The **Activity** tab shows how many subagents are working right now.

#### Chat scrolling only moves when you do
- Whatever you're reading stays put while replies stream, steps finish, pictures load, blocks fold, panes resize or you switch views.
- At the bottom, the chat follows every update; any scroll of yours stops following, and **↓ Latest** brings it back.
- Each chat, subagent and split pane remembers where you were reading, also after a restart, and opens there with the **New** line for anything that came in.

#### Projects are only the folders you add
- A new AIB starts with no projects. Add one with **New project**, or start a chat in a folder. Chats from folders you haven't added stay out of AIB, and nothing on disk is touched.

#### Plan card folds finished steps
- A chat has one plan card. While steps are open it stays at the end of the chat, and each update replaces it.
- Steps in progress come first, then steps to do, then a folded **✓ N done** line.

#### Limits chip shows how much of your plan you've used

<Shot name="limits-chip.png" alt="The Limits chip in its normal, warning and red states" />
- A **Limits** chip after Ctx shows how much of your plan you've used, for example `5h 42% · wk 18%`, or `wk 26%` on plans with only a weekly limit. Hover for reset times.
- It turns to a warning colour from 85% and red when you're blocked.
- Claude Code, Codex and Mistral Vibe get it from their official sources; Qwen shows "limit reached". Agents without an official source get no chip.

### Fixes
- Queued messages no longer wait for a Claude Code reply's background helpers to finish.
- Claude Code chats on the newest models keep their to-do checklist.
- Plan steps in progress spin whenever the chat is working, helpers included.
- Interrupting a reply no longer marks running helpers as interrupted, and helper cards show the right model and run time.
- Scrolling up, even one wheel notch, stops following the chat; following comes back at the very bottom or with **↓ Latest**.
- A chat at the bottom stays there when steps, pictures, approval cards or the terminal appear, and opening a step or **Show all** keeps it in place.
- Opening a chat with unread messages lands on the **New** line, and switching Full / Chat / Prompts keeps your place.
- Long blocks no longer flash open on every update. In Full view, steps still running stay listed until they're done.
- AIB no longer keeps every redrawn screen in memory, and stays fast and smooth to type in long, busy chats.
- AIB opens on the project and chat you had open, also from a new build folder.
- **Files** remembers open folders and shows a hover highlight in light themes.
- The inbox never counts the chat you have open, and its count matches what's inside.
- Codex makes AIB docs on the first try, and tool rows for AIB's own tools show their names instead of an id.
- Messages an agent sends its helpers no longer show as raw "Delegation" blocks.
- A project you pick just before quitting is kept.
- The separate agents & command monitor page is removed; the sidebar, Activity and terminal cover it.
- New app icon: a solid black top hat with a teal rim, easier to see at small sizes.
- File view's **Source | Page** is now **Source | Preview**.

### Tested
Run on the release commit with nothing uncommitted (Windows 11):
- App-side tests: 1,459 passed, 0 failed.
- Page tests: 1,185 passed, 0 failed.
- Worktree end-to-end tests: 20 passed.
- Server comparison tests: 6 of 6 groups passed.
- Includes 57 scroll tests, 33 layout tests and a 3-minute speed test, plus real-build tests for quitting with chats running, updating mid-chat and keeping your project across builds.

Not tested: macOS and Linux builds, beyond building them.

## 0.1.0-beta.7

[Downloads on GitHub](https://github.com/sirkuttin/AIB/releases/tag/v0.1.0-beta.7)

> **Beta.** Builds are not code-signed. Expect rough edges. Install and download notes are the same as in [0.1.0 beta 1](https://github.com/sirkuttin/AIB/releases/tag/v0.1.0-beta.1).

The Merge button now has the agent do the merge. Every Beta agent can be installed from its card. Charts and diagrams in artifacts work offline.

### What's new

#### Merge into main button prompts the agent to merge

<Shot name="06-worktree-changes-merge.png" alt="The Changes tab with Discard and Merge into main" />
- Click **Merge into main** in the Changes tab. AIB sends the chat a merge request, shown as a small "Merge requested" card. There is no confirm dialog.
- The agent can only merge after you click. If it tries without your click, or its work changed after you clicked, nothing is merged and it tells you to click Merge.
- If there are conflicts, the agent fixes them and finishes the merge. Your next message cancels the request.
- The button is greyed out, with the reason, for closed, archived, read-only and Elsewhere chats.

#### Install button on every Beta agent card in Settings

<Shot name="08b-settings-beta-agents.png" alt="Settings, AIB Linking: the Beta agents with their Install buttons" />
- Every Beta agent card has an **Install** button.
  - OpenCode now installs with npm, like the others.
  - Cursor CLI, Goose and Mistral Vibe run the vendor's installer in the card's terminal. The card shows the command before it runs it.
  - If an install fails, the output stays on screen with "Install failed."
- Cards list what the agent needs first: Node.js and, for Mistral Vibe on Windows, uv.
  - Each one shows found, missing or too old, with an **Install Node.js 26 (LTS)** or **Install uv** button.
  - The agent's Install button stays off until they're there.
- Installing or signing in to a Beta agent turns it On, so it appears in New chat right away.
- A Beta agent that says Ready shows in New chat unless you turned it off. Agents that aren't ready show greyed out in the New chat agent list with the reason and **Set up in Settings ›**. (If you had turned a Beta agent off before, it comes back On once.)
- Clicking a button on an agent card in Settings keeps the card where it was on screen. Before, the page jumped.
- **Check again** finds a program you just installed without restarting AIB on Windows. If it still can't, it says to restart AIB.
- Kimi sign-in works. It ran the wrong command before.
- Cards with an API key box have a **Get an API key** link to the provider's key page.
- Qwen has an **API address** box for Alibaba Model Studio keys. Leave it empty to use Qwen's default.
- The Gemini and Qwen notes are corrected from the vendors' own pages.
- API keys are encrypted on disk:
  - Windows seals them to your user account, macOS keeps them in the login Keychain, and Linux in the system keyring (or a file only you can read when there is no keyring).
  - Keys you saved before are encrypted the first time this version starts.

#### Claude Code and Codex cards offer to install Node.js
- If Node.js is missing or too old, the card shows an **Install Node.js** button, the same as the Beta cards.

#### Charts and diagrams in artifacts work offline
- Mermaid, Chart.js and Vega now come with AIB, so artifacts that use them draw without the internet.
- Mermaid blocks in Markdown artifacts are drawn too.

#### Open in Artifacts button on a file tab opens the file in the Artifacts tab
- Before, the button did nothing. Now the file opens in the Artifacts tab, and your file tab stays open.
- When no chat can hold the file, the button is greyed out and says why.
- Error messages now show while a file tab is open. Before, they were hidden.

#### Chat and Prompts views fold a turn's tool calls only once
- In Chat and Prompts views, a turn's tool calls fold under one "Show steps". The second "N steps" fold inside it is gone.

#### Other fixes
- The first message of a new chat is always sent, even if you switch to another chat while the agent starts. Before, it could be lost. If sending fails, the message stays in the box as a draft.
- Links in an agent's error messages are clickable.
- Approval cards show the exact command, path or URL in a code box, with the agent's description under it. The inbox shows the same.
- A new chat no longer shows the previous chat's Changes, Merge, Discard and Files.
- The model menu no longer says "Default (Default (...))".
- Tool rows show paths inside your project, not inside the chat's hidden copy.
- Terminal colours change with the theme, sign-in terminals included.
- A chat scrolled to the bottom stays at the bottom when a question card or the terminal opens.
- In the sidebar, a long chat title gets the whole first line, and its age moves to the second line.

### Tested
- All automated page, server and worktree end-to-end tests, including the comparison with the original Python version.
- Merging, prerequisite checks and installers are tested with a fake terminal. Nothing was really installed.
- **Windows x64:** the build starts and serves its page.
- **Not tested:** the vendor installers (Cursor CLI, Goose, Mistral Vibe), Node.js and uv installs on real machines, macOS, Windows on ARM and Linux.

### Known issues
- The vendor installers haven't been run on a real machine yet. If one fails, the card keeps the output, and you can still run the command yourself.
- OpenCode's npm install is about 500 MB, because it downloads the program for your system.
- On Linux, the first start can take close to a minute, and AIB needs a display to start, even for `serve`.
- With the window split into several chats, file tabs show only in the first pane.

## 0.1.0-beta.6

[Downloads on GitHub](https://github.com/sirkuttin/AIB/releases/tag/v0.1.0-beta.6)

> **Beta.** Builds are not code-signed. Expect rough edges. Install and download notes are the same as in [0.1.0 beta 1](https://github.com/sirkuttin/AIB/releases/tag/v0.1.0-beta.1).

This release keeps your terminals running through restarts and updates, and lets you open any file an agent wrote straight from the chat.

### What's new

#### Terminals survive restarts, crashes and updates

<Shot name="10-terminal-dock.png" alt="The chat terminal docked under the message box" />
- **A chat's terminal now lives in AIB-keeper**, like the chat itself. When AIB restarts, crashes or installs an update, the terminal comes back with the same shell and its recent output, and a running command keeps running.
- While AIB reconnects, the terminal shows "· reconnecting" and picks up by itself.
- **Terminals that agents open** keep running too, and their output is still there after a restart.
- **Ctrl+C works** in terminals.
- **Quitting AIB on purpose still ends your terminals.** Sign-in terminals for Beta agents also end on a restart.

#### Open files from the chat
- **Every write or edit row has an open-file button** in its header, and the file path inside the row is clickable. Both open the file in AIB's file view: beside the chat on wide windows, as a tab otherwise. Ctrl+click opens your editor; right-click gives more options.
- The row's "open ↗" button is now **"editor ↗"**, because it opens your external editor.
- **Files outside the project** (for example in another git worktree) open read-only, labelled "Outside this project", with the branch and repository when AIB can tell. AIB only opens such a file when the chat itself mentioned it.
- Links in a subagent's history look and work like links in the main chat.

### Tested
- Full automated tests on this exact code: page tests, server tests, comparison with the original Python version, worktree tests.
- A real AIB was killed in the middle of a terminal command that printed every 0.1 s: the keeper restarted it in about 6 seconds with the same shell and no gap in the output.
- **Windows x64:** the build started and served its page.
- **Linux x64:** packages inspected (programs and keeper marked executable) and the app served its page headless on Ubuntu (WSL).
- **Not tested:** updating with a terminal command running end to end (covered by a smaller test), macOS (both), Windows on ARM, Linux ARM64.

### Known issues
- On Linux, the first start can take close to a minute, and Linux needs a display to start, even for `serve`.
- With the window split into several chats, file tabs show only on the first pane.

## 0.1.0-beta.4

[Downloads on GitHub](https://github.com/sirkuttin/AIB/releases/tag/v0.1.0-beta.4)

> **Beta.** Builds are not code-signed. Expect rough edges. Install and download notes are the same as in [0.1.0 beta 1](https://github.com/sirkuttin/AIB/releases/tag/v0.1.0-beta.1).

This release gives AIB its new look, keeps your chats running through restarts and updates, and fixes a lot of small things you could see.

### What's new

#### Chats keep running through restarts and updates
- **A small helper, AIB-keeper, now holds your running chats.** When AIB restarts, updates or crashes, the next AIB picks each chat up where it was: no lost replies, nothing sent twice. In Task Manager you see AIB plus AIB-keeper.exe.
- **Install now works while chats are running.** The new version takes them over.
- **If AIB crashes, it comes back in the tray** instead of popping up a window.
- Coming from beta 3: with no chat working, the update hands over at once; with a chat working, that chat finishes first and AIB says why.
- If the keeper can't run, AIB still works as before, and Settings › About AIB says so.

#### New look and themes

<Shot name="12-themes-grid.png" alt="The same chat in four themes" />
- **Bay teal is the new default look.**
- **Settings › Appearance › Theme** with eleven themes, each previewed in its own colours:
  - **AIB:** teal dark (default), teal light.
  - **Accessibility:** high contrast dark, high contrast light, colour-blind safe.

## 0.1.0-beta.1

[Downloads on GitHub](https://github.com/sirkuttin/AIB/releases/tag/v0.1.0-beta.1)

AIB, the **Agent Integration Bay**, is one desktop app for all your coding agents (Claude Code, Codex, OMP) across all your projects. It talks to each agent through ACP, so questions, approvals, plans, subagents and background commands show up as real things you can see and act on. It runs on your computer: no account, no telemetry, and your data stays with you.

> **Beta.** Builds are not code-signed. Expect rough edges.

### Download

| System | File |
| --- | --- |
| Windows (64-bit Intel/AMD) | `AIB-0.1.0-beta.1-windows-x64.zip` |
| Windows on ARM | `AIB-0.1.0-beta.1-windows-arm64.zip` |
| macOS, Apple silicon | `AIB-0.1.0-beta.1-macos-arm64.zip` |
| macOS, Intel | `AIB-0.1.0-beta.1-macos-x64.zip` |
| Linux x64 | `AIB-0.1.0-beta.1-linux-x64.AppImage` or `.deb` |
| Linux ARM64 | `AIB-0.1.0-beta.1-linux-arm64.AppImage` or `.deb` |

`SHA256SUMS` lists the checksum of every file.

### Install

- **Windows:** unzip anywhere (no admin needed) and run `AIB\AIB.exe`. Windows shows a SmartScreen warning because the app isn't signed: choose **More info**, then **Run anyway**. The first run adds AIB to the Start menu.
- **macOS:** unzip and move `AIB.app` to Applications. The first time, right-click it and choose **Open** (it isn't notarized).
- **Linux:** make the AppImage executable (`chmod +x`) and run it, or install the `.deb` (`sudo apt install ./AIB-…deb`). Needs a desktop session (it opens a window).

You also need **Node.js** for the agents (their adapters are small Node programs). The first page sets up your agents: AIB can install Claude Code's and Codex's adapters for you and runs each agent's own sign-in. It never asks for a password or API key.

### What's in it

- Several agents and chats at once, with streaming text, tool calls and diffs, plans, approvals and questions.
- Your saved Claude Code and OMP conversations in the same list, with search (Ctrl+K).
- **One copy per chat:** in a git project each chat works in its own worktree on its own branch, so agents never overwrite each other; the Changes view brings a chat's work back. On by default.
- Agents keep running in a separate background process, so closing or updating the app doesn't cut off a turn.
- Pages and files agents make (artifacts) shown next to the chat.
- Automatic update check (once a day, can be turned off in Settings), with downloads verified against `SHA256SUMS`.

### Tested

- **Windows x64:** used day to day by the developer.
- **Linux x64:** the `.deb` and the AppImage started, served the app and stopped cleanly on Ubuntu (under WSL, with a virtual display). Startup there was slow (about 40 s); not yet tried on a real Linux desktop.
- **Not tested:** macOS (both), Windows on ARM, Linux ARM64. They are built the same way but have never been run. Reports welcome.

### Known issues

- The tray icon has no right-click menu yet. To quit while chats are running in the background, start AIB again (it brings up the open window) or end it in Task Manager.
- Run only one AIB at a time on a computer. Two copies (or an older AIB) on the same data folder take the agent host from each other.
- While this repository is private, the update check can't see new releases.
