Pick a look that's easy on your eyes. Every theme passes a measured contrast check for all text in the app, so none of them
trades readability for style.

## Theme: Settings → Appearance → Theme

Each theme is previewed in its own colours.

| Group | Themes |
| --- | --- |
| AIB | AIB teal (dark), the default · AIB teal (light) |
| Accessibility | High contrast dark · High contrast light · Colour-blind safe dark |
| Editor-style | Dracula-style dark · Monokai-style dark · Nord-style cool dark · Ember (warm, low blue light) · GitHub-style light · Solarized-style light |

**Match system** follows your system's light or dark setting. The terminal and code colouring follow the theme.

## Every theme passes a measured contrast check

Each theme is checked against the WCAG contrast rules for all text in the app, not just the main text.

## Show status symbols

Turn on **Show status symbols** to add ◔ ▲ ✓ ○ ✕ next to the status dots, so status never depends on colour alone. It's
always on in Colour-blind safe dark.

## Text size, code font and spacing

Set the text size, code font and spacing in **Settings → Appearance**, or change the chat text with **Ctrl+=**, **Ctrl+-** and
**Ctrl+0**, and the whole interface with **Ctrl+Shift+=**, **Ctrl+Shift+-** and **Ctrl+Shift+0**. Your layout is saved in
AIB's data folder, so it moves with your data.

## A theme per phone

The phone page has its own theme picker: **Follow PC**, **Match system**, or any theme, saved on that phone. See
[Remote control](/phone/).
